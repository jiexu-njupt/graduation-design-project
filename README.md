# graduation-design-project
毕业设计资料

**【毕设系统填写的一般说明】**

1.任务书、中期检查、外文翻译封面等表格在系统填写，**不要上传附件**。

2.参考文献格式一定要认真检查（参考毕设论文模板），工作规定和论文模板里都有参考文献格式要求，参考文献建议只采用期刊论文，不建议采用硕博士论文、会议论文、书籍、专利等。参考文献在正文中需要**按顺序依次引用**。

3.期刊文章格式示例（期号如查不到可以不写，有刊物如J. Appl. Phys.没有页码，那就写文献编号即可、文献编号不要写起止）：

[序号] 作者1, 作者2, 作者3. 文献标题[J]. 期刊名, 年, 卷(期): 起止页码.


**【参考文献示例与作者姓名规范】**

示例：

[1] Yu F, Huang G, Xu C. An explicit method to extract fitting parameters of industrial solar cells [J]. Renewable Energy, 2020, 146: 2188-2198.

[2] Zhang C, Zhang J, Hao Y, Lin Z, and Zhu C. A simple and efficient solar cell parameter extraction method [J]. J. Appl. Phys., 2011, 110: 064504.

作者姓名说明：

中文作者：按惯例即可。

英文作者：外文文献署名通常名在前，姓在后，如艾尔伯特·爱因斯坦 Albert Einstein。但写到开题报告和毕业论文的参考文献中时，需要姓在前（全称），名在后（首字母），比如Albert Einstein写成 Einstein A（就是这么规定），一个姓名中间不要加逗号或句号（即不要写成 Einstein, A.），作者与作者之间用英文逗号“,”隔开，最后一个作者用英文句号“.”结尾。所有标点符号后加一个英文空格（逗号、句号、冒号均是英文半角输入）。


**【毕业论文规范】**

1.行距设置：
毕业设计内容及各种标题（包括摘要、目录、致谢、参考文献、附录等）的行距设置统一选用 1.25 倍行距。

2.字体设置：
（1）“摘要”（“ABSTRACT”选用“Times New Roman”）、“目录”、“结束语”、“致谢”、“参考文献”等字样均选用“三号黑体”。（2）正文一级标题选用“小三号黑体”；二、三级标题选用“四号黑体”；正文内容选用“小四号宋体”。表格内容和题名应采用宋体5号，图的题名应采用宋体5号，英文和数字使用Times New Roman字体。

3.正文撰写格式：
正文中文用小四号宋体，英文用小四号Times New Roman字体，正文的页眉标注为“南京邮电大学××××届本科生毕业设计（论文）”，页脚标注页码,页码用阿拉伯数字底部居中，小五号 Times New Roman 体字。正文分章节撰写，一级标题用“第一章”、“第二章”、“第三章”等连续编号，每章应另起一页，标题末尾不加标点，标题居中排列。从二级标题开始，用阿拉伯数字连续编号，在不同层次的数字之间加一个下圆点相隔，最末数字后不加标点。如二级标题为“1.1”、“2.1”、“3.1”等，三级标题为“1.1.1”、“2.1.1”、“3.1.1”等。正文中的标题一般不超过三级，标题层次要清晰，均单独占一行。一句话不可单独成段，通常一个段落需至少包含3句话（即3个句号）。

4.表格：
表序号一律用阿拉伯数字分章依序编码，如：第一章表1.1、表1.2等，第二章表2.1、表2.2等。每一表应有简短确切的题名，连同表序号置于表的正上方（居中）。表序必须连续，不得重复或跳跃。表格和题名不得跨页。每个表格都需要在正文中做说明，且说明位置在表格出现之前（不可在表格之后），如“见表1.1”，“表1.1所示”等。表格内容和题名的字号为5号。

5.图：
图序号一律用阿拉伯数字分章依序编码，如：第一章图1.1、图1.2等，第二章图2.1、图2.2等。每一图应有简短确切的图名，连同图序号置于图的正下方（居中，注意与表格要求不同）。图序必须连续，不得重复或跳跃。图和题名不得跨页。每个图都需要在正文中做说明，且说明位置在图出现之前（不可在图之后），如“见图1.1”，“图1.1所示”等。图的题名的字号为5号。

6.公式：
正文中的公式必须编排序号，序号一律用阿拉伯数字分章依序编码，如：第三章式(3-1)、式(3-2)等。公式序号标注于该式所在行的最右边。

7.参考文献：
在论文中引用参考文献时，引出处右上角用方括号标注阿拉伯数字编排的序号，如[1][2][3]等。所有参考文献在正文中必须全部引用，且按照出现顺序编号，如[1]在[2]之前，[2]在[3]之前，以此类推。参考文献通常为期刊论文，格式如下：
[序号] 作者. 文献题名[J]. 刊名, 出版年, 卷号(期号): 起止页码.
